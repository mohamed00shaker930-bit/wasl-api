# wasl-api

Backend for Wasl (وصل). NestJS 11 + Drizzle ORM + PostgreSQL 17. Replaces the Supabase RLS policies, RPCs, triggers and
edge functions of the original Lovable app with explicit REST endpoints, JWT auth and service-layer transactions.

## Run locally
```bash
cp .env.example .env                 # fill JWT secrets; DATABASE_URL defaults to the wasl-ops embedded Postgres
pnpm install
pnpm db:migrate                      # applies src/db/migrations/*.sql
pnpm db:seed                         # permission catalog, app_settings defaults, first super admin (SEED_SUPER_ADMIN_*)
pnpm build && node dist/main.js      # or: pnpm start:dev (nest --watch). NOT `tsx src/main.ts`: tsx drops decorator metadata.
# Swagger UI: http://localhost:3000/api/docs
```
Or with Docker: `docker compose up -d postgres minio` for the databases, `docker compose --profile full up -d` for the whole stack behind Caddy.

## Layout
- `src/db/migrations/*.sql` – ordered SQL migrations (`0000_baseline.sql` is generated by `wasl-ops/db/build-baseline.sh`).
- `src/db/schema/` – Drizzle schema, regenerated with `pnpm db:pull` from a migrated database.
- `src/domain/` – pure business rules ported from the web app (`checkout.ts`, `credit-rules.ts`, `order-status.ts`) with their tests.
- `src/common/auth` – JWT guard, `@Roles`, `@Perms`, force-password-change guard. `src/common/errors` – `{error: <code>}` responses.
- `src/modules/*` – auth, me, catalog (public browsing), wallet, credit, orders, merchant (incl. POS ingest), events (SSE), admin, files, custom-requests.

## Conventions
- Money columns are `numeric` and travel as strings; convert with `num()` / `money()` from `src/domain/money.ts`.
- Every balance change happens inside `DbService.withTx()` after `SELECT … FOR UPDATE`.
- Clients get machine-readable error codes; the Arabic text lives in the clients.
- Web clients (`X-Client` absent) receive the refresh token as an httpOnly cookie on `/api/auth`; `X-Client: mobile` gets it in the body.

## Tests
`pnpm test` runs the domain unit tests. `pnpm test:e2e` runs `test/*.e2e.test.ts` against `TEST_DATABASE_URL`.
Scenario scripts live in `../wasl-ops/scripts/smoke-*.sh`.
